# The Grab Club

Recovered standalone version of the existing Replit website, prepared for GitHub + Netlify.

## Local development
1. Install Node.js (current LTS).
2. Run `npm install`
3. Run `npm run dev`

## Netlify
Build command: `npm run build`
Publish directory: `dist`

Before launch:
- Update product names and selling prices in `src/App.tsx`.
- Replace `hello@yourbrand.example` with the real monitored contact email.
- Add the full artwork catalogue and confirm image permissions.
